## 年付用户最容易踩的三个条款

这三个条款都写在官方文档里，但不会出现在产品页的显眼位置，而它们对年付用户的影响远大于月付。

**第一，到期当天就停服，没有宽限期。** 系统会在到期前 7 天生成续费账单并发邮件，如果绑了信用卡还会自动尝试扣款。到期日当天服务立即暂停；逾期 1、2、3 天各发一次提醒；逾期 5 天服务终止，数据可能无法恢复；逾期 6 天账单自动取消。付款成功后会自动恢复，不需要人工介入。

对月付用户来说，这事最多是“晚几天”；对年付用户来说，一年才遇到一次，很容易因为换了卡、邮箱没看、人出差而错过。到期前把信用卡信息更新好，或者干脆提前手动续费，比什么折扣都重要。

**第二，退款窗口只有 24 小时，且仅限首购。** GoMami 的政策是开通后 24 小时内可申请全额退款，超过 24 小时不退，续费订单不退。退款到账时间分支付方式：支付宝 1–3 个工作日，信用卡 5–10 个工作日，加密货币 1–3 个工作日。另外，因 DDoS 攻击导致 IP 被黑洞的情况不在退款范围内。

年付金额越大，这 24 小时的分量越重。真要年付，建议先用月付跑一周，确认线路在你所在地的实际表现，再决定要不要转成年付。

**第三，流量包只在当期有效，不结转。** GoMami 的流量只计出站，入站不计费，额度按计费周期重置。不够用可以单独买流量包：100GB $6、500GB $30、1TB $60、2TB $120、5TB $300、10TB $600、20TB $1200。但官方明确写了，购买的流量只在当前计费周期有效，不会滚到下个月。官方自己的建议是：如果经常不够用，那就升档，别一直买流量包。

只计出站这一条对建站和中转类用户其实挺友好——入站流量白送，很多商家是把双向加一起算的。至于超流量之后会怎样，官方文档只写“可能被限速，具体策略视套餐规格而定”，没有给出统一数值，第三方有提到限速到 20KB/s，但这只能当参考。

## 常见问题

**流量超了会怎样？** 出站流量跑完后可以买流量包补，但流量包只在当期有效。经常超的话官方建议直接升档。超配额后是否限速、限到多少，官方只说“视套餐规格而定”。

**能中途升级套餐吗？** 官方文档写明目前套餐变更需要开工单联系客服处理，不能自助操作。

**续费价格和首购价格一样吗？** 官方文档没有对续费价作出承诺，只说明续费账单提前 7 天生成。这一点和某些主打“续费同价”的商家不同，年付前最好开工单问清楚。

**支持支付宝吗？** 支持，走 Stripe Alipay，可用人民币支付。

**能装 Windows 吗？** Pulse Pro / Ultra 和 Turin Pro / Ultra 标注了 Windows-ready，系统模板里有 Server 2019 和 Server 2022。
